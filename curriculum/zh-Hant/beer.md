# BoozeTutor 啤酒課程大綱

課程分為若干板塊。每個板塊包含若干課程，每節課程講授一個或多個主題；每個主題都寫明學完後你應能做到什麼。

每個主題都有難度。基礎涵蓋自信地品飲和談論一種酒所需的要點。中級加入熱心愛好者或剛入行者應有的基礎。進階則深入科學、生產細節和產區詳情。你可以為每種酒選擇難度，其課程列表會顯示該難度及以下的主題。

## 1. 啤酒是如何釀造的

### 1.1 啤酒是如何製造的

從穀物到玻璃杯：釀造過程

- **1.1.1 歡迎** (基礎): 了解啤酒課程及其三個等級的整體架構。
- **1.1.2 艾爾與拉格** (基礎): 從酵母和發酵溫度區分艾爾啤酒與拉格啤酒。
- **1.1.3 啤酒如何釀造** (基礎): 說明從糖化到發酵與包裝的各個釀造階段。

### 1.2 啤酒成分

麥芽、啤酒花、酵母、水和輔助原料

- **1.2.1 麥芽** (基礎): 說明麥芽為啤酒帶來的糖分、顏色與風味。
- **1.2.2 啤酒花** (基礎): 說明啤酒花為啤酒帶來什麼，以及釀酒師採購啤酒花的各種形式。
- **1.2.3 酵母** (基礎): 說明酵母在啤酒中的作用，以及艾爾酵母與拉格酵母有何不同。
- **1.2.4 小麥酵母、野生酵母與高絮凝酵母** (中級): 從對啤酒產生的影響來區分小麥酵母、野生酵母與高絮凝酵母。
- **1.2.5 釀造用水** (中級): 說明釀造用水中的礦物質如何塑造啤酒風格。
- **1.2.6 輔料** (中級): 說明釀酒師為何添加輔料，以及輔料會為啤酒帶來哪些改變。
- **1.2.7 四大原料的整合** (基礎): 總結麥芽、啤酒花、酵母和水各自為啤酒帶來的貢獻。

### 1.3 釀造科學

深入了解啤酒花、酵母、水與麥芽

- **1.3.1 啤酒花化學** (進階): 說明啤酒花苦味與香氣背後的化學原理。
- **1.3.2 酵母生物學** (進階): 說明酵母代謝如何產生酒精、酯類及其他風味物質。
- **1.3.3 實務中的水質化學** (進階): 說明釀酒師如何針對不同風格調整釀造用水。
- **1.3.4 製麥與糖化** (進階): 說明製麥與糖化過程中澱粉和酵素會發生什麼變化。

## 2. 品飲與風格

### 2.1 系統性啤酒品酒

感官評估及品酒方法

- **2.1.1 入門** (基礎): 用結構化的方法並排比較三款啤酒。
- **2.1.2 外觀** (基礎): 描述啤酒的顏色、澄清度與泡沫。
- **2.1.3 香氣** (基礎): 描述啤酒的香氣及其強度。
- **2.1.4 風味與口感** (基礎): 描述啤酒的風味與口感。
- **2.1.5 風味從何而來** (中級): 將啤酒的風味追溯至麥芽、烘焙、啤酒花與酵母。
- **2.1.6 餘韻** (基礎): 描述啤酒的餘韻及其持續時間。
- **2.1.7 評鑑啤酒** (基礎): 評鑑一款啤酒的品質，並說明理由。

### 2.2 艾爾啤酒風格

英國傳統、美國精釀及德國艾爾啤酒

- **2.2.1 英式艾爾傳統** (基礎): 介紹英式艾爾的傳統及其主要風格。
- **2.2.2 美式精釀艾爾** (基礎): 介紹美國精釀啤酒廠如何重新詮釋淡色艾爾與 IPA。
- **2.2.3 德式艾爾** (中級): 介紹德式艾爾的各種風格及其釀造方式。
- **2.2.4 酵母與艾爾風格** (中級): 解釋酵母菌株如何決定艾爾的風格。
- **2.2.5 品飲艾爾** (基礎): 在杯中比較來自不同傳統的艾爾。
- **2.2.6 艾爾風格速覽** (基礎): 列出主要的艾爾風格，以及各自的特色。

### 2.3 比利時及大陸艾爾啤酒

特拉普斯特修道院啤酒、農莊啤酒、蘭比克及佛蘭德斯酸啤酒

- **2.3.1 特拉普派與修道院艾爾** (中級): 介紹特拉普派與修道院艾爾，以及它們所釀造的風格。
- **2.3.2 農舍艾爾與小麥啤酒** (中級): 介紹季節啤酒（Saison）、窖藏啤酒（Bière de Garde）與白啤酒（Witbier）。
- **2.3.3 蘭比克** (中級): 解釋自然發酵與蘭比克啤酒家族。
- **2.3.4 法蘭德斯酸艾爾** (中級): 介紹法蘭德斯紅艾爾與棕艾爾，以及它們如何變酸。
- **2.3.5 比利時與酸啤酒風格一覽** (中級): 列出比利時與酸啤酒的各種風格，以及各自的特色。

### 2.4 拉格啤酒風格

皮爾森、淡色拉格、波克、深色及慕尼黑啤酒

- **2.4.1 皮爾森的誕生** (基礎): 解釋皮爾森如何誕生，以及它為何改變了釀酒界。
- **2.4.2 拉格熟成的原理** (中級): 解釋低溫熟成如何讓拉格口感純淨。
- **2.4.3 皮爾森與黑勒斯** (基礎): 介紹德式皮爾森與黑勒斯。
- **2.4.4 深色與季節性拉格** (中級): 介紹杜克爾、慕尼黑季節性拉格、維也納拉格與黑拉格。
- **2.4.5 美式淡拉格** (基礎): 介紹美式淡拉格，以及輔料如何塑造其風味。
- **2.4.6 拉格風格一覽** (基礎): 列出主要的拉格風格，以及各自的特色。
- **2.4.7 品飲拉格** (基礎): 在杯中比較不同的拉格。

### 2.5 小麥啤酒、酸啤酒及精釀啤酒

小麥白啤酒、酸艾爾、強度啤酒及現代創新

- **2.5.1 德式小麥啤酒** (中級): 介紹酵母小麥啤酒與其他德式小麥啤酒。
- **2.5.2 柏林白啤酒與古斯** (中級): 介紹柏林白啤酒與古斯，以及它們如何變酸。
- **2.5.3 烈性艾爾與煙燻啤酒** (中級): 介紹烈性艾爾與煙燻啤酒。
- **2.5.4 現代精釀風格** (中級): 介紹現代精釀風格及其起源。
- **2.5.5 品飲小麥啤酒與酸啤酒** (中級): 在杯中比較小麥啤酒與酸啤酒。
- **2.5.6 小麥啤酒與酸啤酒風格總覽** (中級): 說出小麥啤酒與酸啤酒的各種風格，以及各自的特色。
- **2.5.7 依據風格指南評審** (進階): 依據風格指南評審一款啤酒。
- **2.5.8 依風格品飲** (中級): 在品飲中依風格評估一款啤酒。

## 3. 世界各地的啤酒

### 3.1 啤酒產區及傳統

比利時、德國、捷克、英國、美國及其他地區

- **3.1.1 比利時** (基礎): 描述比利時的釀酒傳統。
- **3.1.2 德國** (基礎): 描述德國的釀酒產區與傳統。
- **3.1.3 捷克** (基礎): 描述捷克的釀酒文化及其拉格啤酒。
- **3.1.4 英格蘭** (基礎): 描述英格蘭的釀酒傳統。
- **3.1.5 蘇格蘭** (中級): 描述蘇格蘭的釀酒傳統。
- **3.1.6 愛爾蘭** (中級): 描述愛爾蘭的釀酒傳統。
- **3.1.7 美國** (中級): 描述美國的釀酒傳統。
- **3.1.8 日本** (中級): 描述日本的釀酒傳統。

### 3.2 啤酒標籤

酒標必須標示的內容及解讀方法

- **3.2.1 標籤必須標示的內容** (中級): 列出啤酒標籤必須包含的內容。
- **3.2.2 各市場的標籤規定** (進階): 比較歐盟、英國、澳洲與紐西蘭的標示規定。
- **3.2.3 自願標示項目** (進階): 說明啤酒標籤上的自願標示項目與品質標章。
- **3.2.4 如何閱讀標籤** (中級): 實際閱讀啤酒標籤。
- **3.2.5 標籤上的風格名稱** (中級): 解讀啤酒標籤上的風格名稱。
- **3.2.6 標籤上的酒精濃度與標示宣稱** (中級): 解讀啤酒標籤上的酒精濃度與標示宣稱。
- **3.2.7 標籤上的產地來源** (中級): 解讀啤酒標籤上的產地與產區資訊。
- **3.2.8 以酒廠所在地作為背景脈絡** (中級): 以酒廠所在地作為理解其啤酒的背景脈絡。

## 4. 侍酒與瑕疵

### 4.1 侍酒、配餐及生啤系統

溫度、酒杯、食物配對及生啤系統

- **4.1.1 飲用溫度** (基礎): 以適當的溫度供應各種啤酒風格。
- **4.1.2 杯具** (基礎): 為啤酒風格選擇合適的杯子。
- **4.1.3 倒酒與餐酒搭配** (基礎): 把啤酒倒好，並與食物搭配。
- **4.1.4 保存** (中級): 妥善保存啤酒以維持新鮮，並說明過濾與巴氏殺菌。
- **4.1.5 包裝穩定性** (進階): 說明巴氏殺菌、過濾與無菌充填如何讓啤酒保持穩定。
- **4.1.6 桶裝啤酒與傳統桶釀啤酒** (中級): 說明桶裝啤酒、傳統桶釀啤酒（cask）與生啤酒系統的運作方式，以及桶釀啤酒如何保存。
- **4.1.7 生啤酒系統工程** (進階): 說明生啤酒系統如何平衡氣體、壓力與溫度。
- **4.1.8 負責任的供酒服務** (基礎): 負責任地供應啤酒，並在必要時拒絕供酒。

### 4.2 異味及啤酒缺陷

識別及預防常見缺陷

- **4.2.1 什麼是異味** (中級): 說明什麼是異味，以及感知閾值的運作方式。
- **4.2.2 雙乙醯與乙醛** (中級): 辨識雙乙醯與乙醛，並說出其成因。
- **4.2.3 高級醇（雜醇油）** (中級): 認識高級醇，並說明其成因。
- **4.2.4 酯類** (中級): 認識酯類缺陷，以及何時需要酯類風味。
- **4.2.5 DMS 與酚類物質** (進階): 認識 DMS 與酚類缺陷，並說明其成因。
- **4.2.6 氧化與污染** (中級): 認識氧化與污染，以及如何預防。
- **4.2.7 光臭味與參考對照表** (中級): 認識光臭味，並學會使用異味參考對照表。
- **4.2.8 閾值訓練** (進階): 說明品評小組如何使用添加標準物的啤酒進行訓練並測定閾值。
- **4.2.9 缺陷品飲** (中級): 在品飲中辨識異味。

### 4.3 最終複習

涵蓋所有啤酒主題的複習測驗

- **4.3.1 最終複習** (基礎): 整合每堂課所學，回答涵蓋整個課程的問題。
