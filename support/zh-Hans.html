BoozeTutor · 支持

期待听到你的声音。请选择最合适的方式。

给我们发邮件

无论是程序问题、内容更正、意见反馈还是其他事情，邮件都是联系我们的最佳方式。我们会尽量在几天内回复。

发邮件至 boozetutor@gmail.com

报告问题

请在邮件中告诉我们你当时在做什么、发生了什么。以下信息能帮我们更快找到问题：

  1. 应用的版本和构建号（见 设置 › 关于 BoozeTutor）。
  2. 你的设备及其 iOS、iPadOS 或 macOS 版本。
  3. 如果问题显示在屏幕上，请附上截图。

已知问题与功能建议

你也可以在 GitHub 上浏览未解决的问题并提交新问题，方便跟进已报告的问题，或公开提出功能建议。
